# Contributing to Flisk projects

Thanks for helping. This guide applies to every repository in the [flisk-sh](https://github.com/flisk-sh) organization that does not have its own `CONTRIBUTING.md`. The main CLI has a longer guide: [flisk-sh/flisk CONTRIBUTING](https://github.com/flisk-sh/flisk/blob/main/.github/CONTRIBUTING.md).

## Before you start

- **Say hello** on [Discord](https://discord.gg/qMu5Xn8Kaq) and tell us what you want to work on. We help you pick a task.
- **Small fixes** (typos, broken links, one-line bugs): open a pull request directly.
- **Bigger changes**: open an issue first so we can agree on the approach before you spend time on it.

## Making a change

1. Fork the repository and create a branch from the default branch.
2. Keep the pull request focused on one change.
3. Add or update tests when you change behavior, if the repository has tests.
4. Run the repository's checks locally (see its README) before you push.
5. Sign off your commits for the [Developer Certificate of Origin](https://developercertificate.org/): `git commit -s`.

## Pull requests

Describe what changed and why, and how you checked it. We aim to reply within one working day.

## Code of Conduct

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
